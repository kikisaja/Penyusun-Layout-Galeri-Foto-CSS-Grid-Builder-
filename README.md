# Proyek 73: CSS Grid Builder (Penyusun Layout Galeri Foto)

Proyek ini adalah alat interaktif berbasis **HTML5, CSS3, dan Vanilla JavaScript** untuk merancang tata letak galeri foto menggunakan modul **CSS Grid Layout**. Dibuat khusus untuk tingkat pemula/SMK agar dapat memvisualisasikan bagaimana properti `grid-template-columns`, `gap`, dan dimensi item bekerja secara langsung.
